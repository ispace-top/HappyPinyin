## 1. 设计理念

### 1.1 设计哲学

HappyPinYin 的设计遵循 **"玩中学，学中乐"** 的核心理念。每个像素、每种颜色、每段动画都服务于一个目标：**降低 5-8 岁儿童的学习焦虑，让拼音学习变成一场愉快的探索游戏**。

### 1.2 情感关键词

| 关键词 | 视觉表达 | 设计策略 |
|--------|----------|----------|
| **温暖** | 柔和圆角、暖色调点缀 | 大面积使用柔和中性色作为背景，暖色仅用于强调和引导 |
| **活泼** | 马卡龙糖果色系、弹性动画 | 分类颜色鲜明但不刺眼，动画使用 ease-out 弹性曲线 |
| **安全** | 大触控区域、清晰边界 | 所有交互元素 >= 48dp，卡片边框和阴影明确区分可点击区域 |
| **鼓励** | 正向反馈动画、角色陪伴 | 错误不惩罚（不可用选项灰显而非报错），成功有撒花+音效 |
| **清晰** | 大字号、高对比文字、分组明确 | 拼音字母最小 28px，分类使用标签+颜色+图标三重编码 |

### 1.3 品牌个性

| 维度 | 描述 |
|------|------|
| **人格** | 像一个耐心的幼儿园老师 + 一个会魔法的玩伴 |
| **语调** | 鼓励式、惊叹式（"太棒了！""你真厉害！"），避免命令式 |
| **视觉记忆点** | 小熊猫"拼拼"吉祥物 + 糖果色分组卡片 + 拼读合并动画 |

### 1.4 核心设计原则

1. **渐进呈现 (Progressive Disclosure)**：每个页面/步骤只展示当前任务相关的元素。拼读构建器每次只激活一个选择步骤，完成后方可进入下一步。
2. **即时反馈 (Immediate Feedback)**：所有点击操作 100ms 内给出视觉响应（缩放、颜色变化），发音加载 500ms 内显示加载状态。
3. **容错设计 (Forgiving Design)**：选择操作可随时回退；不可用选项灰显而非隐藏（让儿童理解"存在但不能选"）；没有"死胡同"状态。
4. **冗余编码 (Redundant Coding)**：信息状态不单一依赖颜色区分，同时使用标签文字、图标、位置、形状等多重线索。
5. **移动端优先 (Mobile-First)**：所有设计决策首先在 360px 宽度下验证，再向上适配平板和桌面端。

## 2. 色彩系统

### 2.1 设计决策说明

**Why this palette**: 马卡龙/糖果色系具有高明度、低饱和度的特点，视觉上柔和友善，不会对儿童眼睛造成刺激。色彩饱和度的选择经过刻意控制（S 值维持在 40%-65%），确保大面积使用时不会引起视觉疲劳。

**色彩语义**: 每种颜色被赋予明确的教学语义，帮助儿童建立"颜色-类别"的条件反射记忆。声母用蓝色系（天空、海洋的联想——"开始"），韵母用粉色系（花朵的联想——"丰富"），整体认读音节用绿色系（草地的联想——"完整"）。

### 2.3 色彩使用规则

| 规则 | 说明 |
|------|------|
| 分类色仅用于 Tab 标签、卡片边框和分组标题背景 | 不在大面积区域使用高饱和色 |
| 文字色仅使用 `neutral-600` ~ `neutral-900` | 彩色从不用于正文文字（无障碍要求） |
| 卡片背景使用 50-100 色阶（极浅色） | 确保卡片上文字对比度 >= 4.5:1 |
| 主色 `primary-500` 仅用于关键 CTA 按钮和导航高亮 | 每屏 CTA 色使用不超过 3 处 |
| 成功/警告/错误色仅用于状态反馈 | 不在常态界面使用功能色 |
| 所有彩色元素必须有无色版本（黑暗模式兼容准备） | 当前暂不实现暗黑模式，但色板体系应支持未来扩展 |

### 2.4 声调色彩编码

```
声调色（用于声调选择器和结果展示）:
  一声（阴平）: #EF4444 (red-500)     — 高高平平，红色表示高而平
  二声（阳平）: #F59E0B (amber-500)   — 向上扬起，橙色表上升
  三声（上声）: #22C55E (green-500)   — 先降后升，绿色表曲折
  四声（去声）: #3B82F6 (blue-500)    — 向下降低，蓝色表下降
```

**Why these colors**: 声调颜色采用"视觉韵律"——一声红（平稳的高线）、二声橙（上坡）、三声绿（山谷）、四声蓝（下坡），利用色彩的心理暗示帮助儿童建立声调与视觉符号的映射。单字拼读不存在轻声，拼读构建器仅使用四个声调。

## 3. 字体系统

### 3.1 字体选择

```
字体栈定义:

--font-display: "PingFang SC", "Noto Sans SC", "Microsoft YaHei", sans-serif;
  → 用于: 页面标题、卡片拼音字母、结果展示大字

--font-body: "PingFang SC", "Noto Sans SC", "Hiragino Sans GB", "Microsoft YaHei", sans-serif;
  → 用于: 正文、按钮文字、标签、说明文字

--font-mono: "SF Mono", "Cascadia Code", "Consolas", monospace;
  → 用于: IPA 国际音标注音（教师模式）
```

**字体选择理由**:
- **PingFang SC** — macOS/iOS 系统默认中文黑体，字形规范，对拼音带调字母（如 ā á ǎ à）支持完善
- **Noto Sans SC** — Google 开源字体，跨平台一致性最好，对"ü"等特殊字符渲染稳定（通过 Google Fonts 按需加载）
- **Microsoft YaHei** — Windows 系统备选，覆盖率高
- **Noto Sans SC 按子集加载策略**: 仅加载拼音所需字符子集（Latin Extended-A + 基本拉丁 + CJK 核心），控制字体文件 < 80KB

### 3.2 字号层级体系

```
Type Scale (基于 Modular Scale 1.25):

层级          | rem  | px   | 用途
-------------|------|------|-----------------------------------
display-lg   | 3.00 | 48px | 首页品牌名、拼读结果大字
display-md   | 2.25 | 36px | 页面主标题
display-sm   | 1.75 | 28px | 分组标题、步骤标题
-------------|------|------|-----------------------------------
title-lg     | 1.50 | 24px | 卡片拼音字母（浏览页）
title-md     | 1.25 | 20px | 卡片拼音字母（构建器选择区）
title-sm     | 1.13 | 18px | 分类Tab标签、按钮文字
-------------|------|------|-----------------------------------
body-lg      | 1.00 | 16px | 正文、提示文字（儿童友好大号）
body-md      | 0.88 | 14px | 辅助说明、分组标签
body-sm      | 0.75 | 12px | 页脚信息、IPA 注音
caption      | 0.63 | 10px | 声调标记辅助说明
```

### 3.3 字重使用规范

```
字重    | 使用场景
--------|------------------------------------------
700     | 结果展示大字（display-lg）、拼读完成音节
600     | 页面主标题、Tab 激活态
500     | 拼音卡片文字、按钮文字（默认字重）
400     | 正文、提示气泡文字、选项文字
300     | 辅助说明文字（极少使用，对比度可能不足）
```

### 3.4 行高规范

```
字号      | 行高  | line-height (CSS)
---------|-------|-------------------
48px     | 1.2   | 适合单行大字展示
36px     | 1.25  | 页面标题
24-28px  | 1.3   | 卡片拼音字母
16-20px  | 1.5   | 正文、按钮、提示
12-14px  | 1.6   | 辅助说明
```

### 3.5 拼音特殊字符处理

| 场景 | 处理方式 |
|------|----------|
| 带声调韵母（如 ā á ǎ à） | 优先使用 Unicode 组合字符（U+0101 等），备选 plain + 声调标记叠加 |
| "ü" 字符显示 | 指定 font-family 中包含 Noto Sans SC，并对 ü 使用 `font-feature-settings` 确保正确渲染 |
| 轻声圆点（·） | 使用 U+00B7 (Middle Dot)，字号略小（0.8em），颜色 `neutral-400` |
| 拼音结果大小写 | 拼音始终以小写字母显示（教学规范），声母呼读音提示用 tooltip 展示 |

### 4.2 圆角系统

```
Radius Tokens:

Token         | px   | 使用场景
--------------|------|-------------------------------
radius-none   | 0    | 表格线、分割线
radius-sm     | 4    | 小标签、徽章、声调指示器
radius-md     | 8    | 按钮、输入框、Tooltip、气泡
radius-lg     | 12   | 拼音卡片、选择器面板、Tab 标签
radius-xl     | 16   | 模态框、大面板、结果展示卡片
radius-full   | 9999px | 圆形头像（小熊猫）、药片形标签、圆形按钮
```

**Why 12px 卡片圆角**: 对于儿童产品，圆角比锐角更具亲和力和安全感。12px 是卡片圆角的"甜点值"——圆润但不失辨识度，在 64px 卡片上占约 19% 的比例，视觉柔和舒适。

### 4.3 阴影系统

```
Elevation Tokens (仅用于桌面端，移动端扁平化):

Token         | CSS box-shadow
--------------|----------------------------------------------
shadow-none   | none
shadow-xs     | 0 1px 2px rgba(0,0,0,0.04)
shadow-sm     | 0 1px 3px rgba(0,0,0,0.06), 0 1px 2px rgba(0,0,0,0.04)
shadow-md     | 0 4px 6px rgba(0,0,0,0.05), 0 2px 4px rgba(0,0,0,0.04)
shadow-lg     | 0 10px 15px rgba(0,0,0,0.06), 0 4px 6px rgba(0,0,0,0.04)
shadow-xl     | 0 20px 25px rgba(0,0,0,0.08), 0 10px 10px rgba(0,0,0,0.04)
shadow-glow   | 0 0 20px rgba(255,107,26,0.15)  ← 成功/高亮光晕
```

**Why 极浅阴影**: 儿童产品应避免强烈阴影造成的"距离感"和"重力感"。阴影在此主要服务于"可点击性暗示"（卡片看起来可以被按下），而非营造空间深度。

|------|------|------|----------|
| **idle** (待机) | 4帧 | 循环 (3s) | 页面加载后、用户 15s 无操作 |
| **wave** (挥手) | 6帧 | 单次 (1s) | 首次进入页面 |
| **nod** (点头) | 3帧 | 单次 (0.5s) | 用户完成一个步骤选择 |
| **jump** (跳跃) | 8帧 | 单次 (0.5s) | 拼读完成、成功反馈 |
| **clap** (拍手) | 4帧 | 循环2次 (0.4s) | 拼读成功（与撒花同时） |
| **shake_head** (摇头) | 4帧 | 单次 (0.4s) | 用户点击不可用选项 |
| **think** (思考) | 6帧 | 单次 (1.5s) | 用户停留 15s 未操作 |
| **spin** (转圈) | 8帧 | 单次 (1s) | 连续完成 5 次拼读 |

#### 技术实现
- **格式**: Lottie JSON (dotLottie) 或 CSS Sprite Sheet (PNG, 2x Retina)
- **帧率**: 12fps（平衡流畅度和资源体积）
- **资源体积**: 每个动画 < 30KB（Lottie）/ < 15KB（Sprite）
- **加载策略**: idle 动画预加载；其他动画按需懒加载（`IntersectionObserver` 触发）

#### 提示气泡

```
气泡样式:
  background: neutral-0 (white)
  border: 2px solid primary-200
  border-radius: radius-md (8px)
  padding: space-2 space-3 (8px 12px)
  font: body-md (14px) / 500
  color: neutral-700
  box-shadow: shadow-sm
  三角指示器: 6px, 指向角色头部

气泡位置: 角色上方 (bottom-center align)
动画: 渐显 (opacity 0→1, 0.2s ease-out)
```

## 9. 交互动效

### 9.1 动效设计原则

1. **动画服务于认知，而非装饰**：所有动效都帮助儿童理解发生了什么（状态变化、空间关系、因果关系）
2. **时长控制在儿童注意力窗口内**：所有 UI 动画 < 0.5s，教学动画 < 2s
3. **采用物理隐喻**：缩放 = 按下（压力），滑动 = 空间移动，弹跳 = 庆祝（拍皮球感）
4. **尊重用户偏好**：`prefers-reduced-motion: reduce` 时禁用所有非必要动画，仅保留透明度变化

### 9.2 页面过渡动画

```
页面切换 (BrowserPage ↔ BuilderPage):
  当前页: fadeOut + slideLeft (0.2s, ease-in)
  新页面: fadeIn + slideRight (0.2s, 延迟 0.2s, ease-out)
  总时长: 0.4s

  实现: CSS transition on route change
  prefers-reduced-motion: 仅有 0.2s fade (无位移)

页面内滚动到区域 (拼读构建器步骤切换):
  scroll-behavior: smooth (默认)
  滚动到目标区域 (0.3s)
  目标区域高亮 brief flash (primary-100 bg, 0.5s 后消失)
```

### 9.4 缓动函数标准化

```
项目中统一使用的 CSS easing 函数:

--ease-default:    cubic-bezier(0.4, 0, 0.2, 1);       // Material standard
--ease-in:         cubic-bezier(0.4, 0, 1, 1);          // 入场加速
--ease-out:        cubic-bezier(0, 0, 0.2, 1);          // 出场减速
--ease-in-out:     cubic-bezier(0.4, 0, 0.2, 1);        // 对称缓动

```

### 9.5 拼读合并动画详解

这是整个应用的核心教学动画，需要精确的时间轴编排：

```
时间轴 (总计 1.2s):

t=0.0s:  声母卡片(左)和韵母卡片(右)同时开始向中心滑动
        声母卡片: translateX(0 → -40%)
        韵母卡片: translateX(0 → +40%)
        easing: ease-in-out

t=0.4s:  两张卡片在中心位置碰撞
        碰撞效果: 光晕 (0.1s, primary glow 闪现)

t=0.5s:  两张卡片合并为一张结果卡片
        合并效果: 两张卡片 opacity 0→1 平滑过渡到新卡片
        新卡片背景: gradient(声母分组色 → 韵母分组色)

t=0.7s:  声调标记从上方弹入
        声调符号: translateY(-20px) → translateY(0) + scale(0.5) → scale(1)
        easing: ease-out-back
        延迟: 0.1s (相对于 t=0.6s)

t=0.9s:  结果卡片放大 + 光晕
        scale(1) → scale(1.15) → scale(1)
        box-shadow: 0 0 0 0 → 0 0 30px rgba(255,107,26,0.3) → 0 0 0 0
        easing: ease-out
```

### 9.6 prefers-reduced-motion 适配

```css
@media (prefers-reduced-motion: reduce) {
  *,
  *::before,
  *::after {
    animation-duration: 0.01ms !important;
    animation-iteration-count: 1 !important;
    transition-duration: 0.01ms !important;
  }

  /* 保留必要的状态反馈动画 */
  .playing-indicator {
    animation-duration: 0.5s !important;  /* 声波仍需可见 */
  }
}
```

当 `prefers-reduced-motion: reduce` 时：
- 页面切换：仅 opacity 渐变 (0.1s)
- 卡片点击：无缩放，仅颜色变化
- 拼读合并动画：直接显示最终结果（无过渡过程）
- 撒花动画：静态星星图标替代
- 小熊猫动作：仅显示表情静态帧 + 气泡文字
- 声波动画：保留（功能需要的状态指示）

### 12.3 关键实现要求

1. **所有可交互元素必须是 `<button>` 元素**（不是 `<div onclick>`），以确保键盘和无障碍访问
2. **卡片网格使用 CSS Grid**：`grid-template-columns: repeat(auto-fill, minmax(64px, 1fr))` 实现自动换行
3. **所有动画使用 `transform` 和 `opacity`** 实现（避免触发布局重排），确保 60fps
4. **语音播放必须通过用户手势触发**（`click` 事件回调中直接调用 `speechSynthesis.speak()`）
5. **步骤指示器使用 `<nav>` + `<ol>` 语义结构**，当前步骤使用 `aria-current="step"`
6. **移动端优先开发**：先以 360px 宽度实现所有功能，再向上适配
